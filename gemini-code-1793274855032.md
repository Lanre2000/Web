# GEMINI.md - BTC Investment Web Application Specifications

## Project Overview
The **BTC Investment Web Application** is a multi-tier crypto yield platform featuring user authentication, email OTP verification, KYC compliance workflows, and role-based access control (RBAC) separating User and Admin dashboards.

## State & Architecture Schema
All application state operates under strict role-based views.

```javascript
const AppState = {
  currentUser: {
    id: "usr_101",
    email: "trader@example.com",
    role: "USER", // "USER" | "ADMIN"
